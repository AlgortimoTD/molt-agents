# documents/

<!-- FICTIONAL DOCUMENT: invented production company for the directorio-freelancers plugin demo. No person, company or client is real. -->

This is where the photos or PDFs of the freelancers' certificates go. One file per
certification, with a name that says whose it is and which one, for example
`ariel-quintero-heights-course-2027-03.pdf`. The person's card points to the file in its
certifications table; a certification with a date but no file here shows up in the weekly
sweep as "no supporting document".

Drop the file and tell me in the chat whose it is and which certification it is; I update
the card.

In the demo the supporting files do not exist as PDFs: the cards name them so the sweep can
tell "with document" from "no supporting document" by reading the table, and the folder only
holds this README. In a real installation the documents are here.

# outputs/

What the directory produces on its own:

- `directory.md`: the index of the whole pool (name, specialties, channel, valid
  certifications, last shoot). Regenerated on every sweep and whenever a card changes. It is
  the file to open from the phone.
- `expiries-YYYY-MM-DD.md`: the report of each weekly sweep, by tier and by person.
- `audits/YYYY-MM-DD-audit.md`: the report of each audit.
- `how-to-operate-the-directory.md`: the operating guide.

Nothing in this folder is edited by hand: it is regenerated.

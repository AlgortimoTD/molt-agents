# salidas/

Lo que el directorio produce solo:

- `directorio.md`: el índice de todo el pool (nombre, especialidades, canal, certificaciones
  vigentes, última producción). Se regenera en cada barrido y cuando cambia una ficha. Es el
  archivo para abrir desde el teléfono.
- `vencimientos-AAAA-MM-DD.md`: el reporte de cada barrido semanal, por tramo y por persona.
- `auditorias/AAAA-MM-DD-auditoria.md`: el reporte de cada auditoría.
- `como-operar-el-directorio.md`: la guía de operación.

Nada de esta carpeta se edita a mano: se regenera.

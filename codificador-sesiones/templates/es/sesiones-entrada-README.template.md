# sesiones/entrada

Pega aquí el transcript de una sesión que no esté en Fathom (Nota, una transcripción manual, un
audio transcrito aparte). Un archivo por sesión, con el grupo en el nombre si puedes:
`AAAA-MM-DD-g3-grupo-focal.md`.

Después dile al agente "codifica el transcript que está en entrada". Cuando lo codifique, el
archivo sale de aquí y su texto queda completo en la sesión codificada.
